# CalDashPro

Calibration management platform for instrument registry, calibration workflow, standards traceability, certificates, work orders, scheduling, maintenance, inspections, notifications, analytics, and audit history.

## Stack
- Next.js + TypeScript
- Supabase (PostgreSQL, Auth, RLS)
- Cloudflare Workers deployment via vinext

Copy `.env.example` to `.env.local` for local development. Never commit real environment values.
